# Number of ROIs in a layer

Number of ROIs in a layer

## Usage

``` r
sg_roi_layer_n(layer, call = rlang::caller_env())
```

## Arguments

- layer:

  An
  [sg_roi_layer](https://cttir.github.io/segmantR/reference/sg_roi.html).

- call:

  The calling environment, for error reporting.

## Value

An integer scalar.
