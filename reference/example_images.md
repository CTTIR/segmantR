# Example segmantR images

Three synthetic image types are available:

- he_breast:

  64x64 single-channel matrix simulating an H&E stained breast tissue
  section with approximately 20 cell-like blobs.

- fluorescence_nuclei:

  64x64 single-channel matrix simulating DAPI-stained nuclei with
  approximately 15 bright spots on a dark background.

- multiplex_4ch:

  64x64x4 array simulating a 4-channel multiplex panel (DAPI, CD3, CD8,
  PanCK) with approximately 18 cells.

## Format

An `sg_image` object.
