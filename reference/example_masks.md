# Example segmantR masks

Three synthetic mask types are available, each corresponding to an
example image type. Masks are integer matrices where 0 is background and
positive integers are cell IDs.

## Format

An `sg_mask` object.

## Details

Example masks for segmantR

Synthetic 64x64 label matrices matching the example images. Generated on
the fly by
[`sg_example_mask`](https://cttir.github.io/segmantR/reference/sg_example_mask.md).
