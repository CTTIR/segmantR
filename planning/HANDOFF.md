QuPath/StarDist-Interop), consumer contract
`qupflowR/setup/qupathr-build-kit/docs/24_SEGMANTR_INTEROP.md` plus the shared

`docs/14_WORKFLOW_BUNDLES.md`. annotatR's plan
(`annotatR/planning/INTEROP_HSI_PLAN.md`) was read for alignment only. No file
outside this repository was changed; nothing was committed, tagged or pushed;
no patient data were read or downloaded; no model weights were downloaded.

| D11 | Object identity = legend `object_id` (deterministic UUID-shaped until materialised, then preserved through corrections, exports and QuPath). |
| D12 | `sg_app()` builds the app from package code; `sg_run_app()` keeps setting the legacy option only for direct `inst/shiny` launches. |
| D13 | segmantR never starts QuPath; QuPath evidence runs through an opt-in test lane and `data-raw/qupath-evidence/run_evidence.R`; version detection reads jar names. |
| D14 | Control service `segmantR-control-v1` documented as planned (`sg_control_capabilities()`); no server functions exported. |
| D15 | Attaching the package no longer initialises Python (spec: optional backends checked at the point of use). |

* **Interchange** (`R/interchange*.R`, `R/inventory.R`, `R/tiff-io.R`,

  `sg_stage_mask()`, `sg_review_mask()`, `sg_replace_mask()`; additive fields
  on `sg_image`/`sg_mask`.
* **Protocols** (`R/protocols.R`, `R/protocol_run.R`, `R/cleanup.R`,
  `R/hsi.R`, 10 protocol files): `sg_protocol_list/schema/get/validate/run()`,
  `sg_cleanup_labels()`, `sg_select_channel()`, `sg_read_envi()`,
  `sg_envi_info()`; `sg_segment_propagate(engine =)`.
* **DNN / datasets / models** (`R/dataset.R`, `R/training_stardist.R`,
  `R/model.R`): `sg_dataset_manifest()`, `sg_prepare_training_data()`,
  `sg_validate_training_manifest()`, `sg_train_stardist()`,
  `sg_predict_model()`; model bundles with `model_card.json` (v1),
  `runtime.json`, `dataset_manifest.json`, `license.json`, `checksums.sha256`.
* **QuPath / StarDist** (`R/qupath.R`, `R/stardist_adapter.R`,
  `inst/qupath/segmantR_{stardist,import,export}.groovy`):
  `sg_export_qupath()`, `sg_import_qupath()`, `sg_stardist_capabilities()`,
  `sg_stardist_manifest()`, `sg_stardist_parameter_map()`.
* **Shiny**: `sg_app()`, `sg_control_capabilities()`; `inst/shiny/segmantR/app.R`
  is a thin wrapper.
* **Docs**: roxygen for all exports, README section, NEWS, vignette
  `vignettes/protocols-and-interop.Rmd`, `inst/interop/INTEROP.md`
  (versions, invariants, runtimes, HSI semantics, licenses, security,
  migration, planned control contract), fixture provenance
  `tests/testthat/fixtures/README.md`.
* **Bug fixes found on the way**: transposed arrays from `sg_read_image()` via
  imager/EBImage; `sg_preprocess()` dropped its history; `sg_segment_cellpose()`
  broke on Cellpose 3.x (`tile`); five robustness/security issues from an
  independent review (malformed 4–7 byte TIFF crash, whole-bundle exactness flag
  masking a wrong exact feature, `list.files()` following symlinked
  directories, unchecked directory entries in model archives, unvalidated
  legacy model-card weights), each with a regression test.
